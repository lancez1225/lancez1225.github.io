# Wenkai Zhu — Personal Website

Personal website: **https://lancez1225.github.io/**.

Hosted with GitHub Pages from the root of the `main` branch.

## Publish with GitHub Pages

1. Use the public repository `lancez1225/lancez1225.github.io`.
2. Place this directory's contents, including `.nojekyll`, at the root of the `main` branch.
3. In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**.

No build step or dependencies are required. GitHub Pages serves `index.html` directly.

## Files

- `index.html` — website content and navigation.
- `styles.css` — responsive styling.
- `favicon.svg` — site icon.
- `assets/Wenkai_Zhu_CV_2027.pdf` — downloadable CV.
- `assets/hc-mvmm-qualitative.png` and `assets/hc-mvmm-overview.jpg` — research images.
- `.nojekyll` — disables Jekyll processing.

This directory contains only website files and these publishing instructions; no credentials or hosting account configuration are included.
